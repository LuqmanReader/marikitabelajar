HOW TO READ THIS SURFACE The terrain is estimated from 3,000 reproducible simulated paths with bandwidth-adaptive density smoothing. The horizontal plane contains time and percentage return; surface height is probability density (per percentage-point return), not the probability of one exact price. The coloured cross-section ridges show how the density widens and its peak falls. A widening ridge means greater dispersion over time; the cards above quantify the change. Surface colour shows concentration relative to each time slice, while height represents actual density. The coloured longitudinal lines mark model-based 5th, median, and 95th percentile outcomes.

06 / Quant Academy — Decode the Engine

LEARN BY INTERROGATING THE MODEL
01 — What is a quant?

Quantitative researchers develop mathematical models of risk, pricing and markets. Their output is useful only when assumptions, data quality and out-of-sample performance are scrutinised.

02 — Log returns and price ratios

Daily log return rₜ = ln(Pₜ/Pₜ₋₁). Log returns add across time, unlike ordinary percentage returns. Historical means should not be mistaken for stable future returns.

03 — Distribution, variance and tails

Standard deviation describes dispersion, but it does not capture every kind of financial risk. The normal distribution tends to underestimate certain extreme market moves.

04 — The simulator's mechanics

Each path draws independent random shocks and compounds log returns over the horizon. The 3D surface shows adaptively smoothed probability densities from 3,000 seeded simulations across the forecast horizon, with a stable comparison scale that can be toggled to auto-fit. The headline threshold probability uses the matching lognormal model formula, rather than relying on the displayed sample frequency. The surface begins after the first few simulated steps because a point-mass initial value has no finite density.

05 — What is a meaningful backtest?

Freeze all information at each historical forecast date, score predictions against later outcomes, and compare them with simple alternatives. Avoid using future revisions and tuning to test data.

06 — Build a testable hypothesis

Example: Does higher realised volatility improve forecasting of a six-month 10% decline? Specify the target, predictor, training window, evaluation window and metric before looking at results.
